# Mechanical Interfaces

## ARM module

ARM01 is the master mechanical reference. ARM02 through ARM12 use the same interface contract.

| Interface | Reference | Requirement |
|---|---|---|
| Base mount | 180 x 180 mm conceptual plate | Final hole pattern by chassis design |
| Upper link | 400 mm nominal | Final section sized for payload/load case |
| Forearm | 400 mm nominal | Final section sized for payload/load case |
| Telescoping extension | Up to 400 mm conceptual | Positive stops and retention required |
| Wrist | Modular flange | Tool-specific adapter permitted |
| Harness | Protected routing | Strain relief and bend-radius control required |

## Design rules

- Keep all arm-to-chassis mounting datums identical.
- Keep actuator and bearing interfaces replaceable.
- Provide mechanical hard stops independent of software limits.
- Prevent cable motion from becoming a pinch or snag hazard.
- Record final tolerances, fastener grades, bearing preload, and torque values in released drawings.

The dimensions above are reference values only. They must not be treated as certified fabrication dimensions without structural and tolerance analysis.
