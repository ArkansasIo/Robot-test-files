# ARM12 Assembly Sequence

This sequence is a controlled prototype workflow, not a certified production procedure.

1. Inspect all structural parts, bearings, fasteners, harnesses, and actuator interfaces.
2. Install the ARM01 base plate and verify the mounting datum.
3. Install the base joint bearing and actuator fixture.
4. Install the upper link and verify free mechanical travel without powered actuation.
5. Install the elbow bearing and forearm assembly.
6. Install the telescoping forearm mechanism with hard mechanical stops.
7. Install the wrist/tool flange and verify the mechanical interface.
8. Route power, communications, and sensor wiring with independent strain relief.
9. Connect the local controller and verify connector polarity and shielding.
10. Verify the E-stop chain with actuators mechanically unloaded.
11. Perform sensor-only bring-up.
12. Perform single-axis fixture testing at reduced limits.
13. Perform multi-axis low-speed testing inside a controlled test envelope.
14. Validate limits, fault handling, thermal monitoring, and E-stop behavior.
15. Repeat the validated procedure for ARM02 through ARM12.

## Prototype rule
Do not install a payload or permit personnel inside the motion envelope until structural, actuator, thermal, control, and safeguarding calculations have been completed and independently reviewed.
